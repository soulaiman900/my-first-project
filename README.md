# Calculateur d'Âge - Age App

Premier projet réalisé par **Soulaiman Hlimi** 
Étudiant en Développement Digital - ISTA NTIC Tanger - DD105 S1

### 📝 Description
Application de bureau simple qui permet de calculer l'âge d'une personne à partir de son année de naissance.

### ⚙️ Fonctionnalités
- Saisie de l'année de naissance
- Calcul automatique de l'âge
- Interface graphique simple et intuitive

### 💻 Technologies utilisées
- Python
- Tkinter (Interface graphique)
- Datetime

### 📂 Fichiers du projet
- `app.py` : Code source principal
- `age_calculator.exe.zip` : Application exécutable prête à l'emploi
